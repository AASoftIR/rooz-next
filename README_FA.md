# Rooz 0.4.5 — نصب یکپارچه AppImage و تشخیص مشکل صدا

**مهم:** خطای `curl: symbol lookup error ... libcurl.so.4` مربوط به فراخوانی `curl` در نسخه‌های قبلی است. نسخه 0.4.4 و 0.4.5 برای Groq از HTTP بومی Rust استفاده می‌کنند. اگر همچنان این خطا را می‌بینید، احتمالاً نسخه قدیمی باز است یا AppImage قدیمی اجرا می‌شود.

### جایگزینی نسخهٔ جدید و حفظ اجرای خودکار در KDE

1. از منوی Tray گزینه **Quit completely** را بزنید یا دستور `~/.local/bin/rooz --quit` را اجرا کنید.
2. AppImage جدید را از صفحهٔ دانلود serv00 بگیرید (طبق راهنمای `SERV00_DEPLOY.md`).
3. در پوشه سورس این نسخه، اسکریپت زیر را اجرا کنید (نام فایل دانلودشده را جایگزین کنید):

```bash
bash scripts/install-appimage.sh ~/Downloads/Rooz_0.4.5_amd64.AppImage
```

اسکریپت AppImage را در مسیر ثابت `~/.local/bin/rooz` جایگزین می‌کند، از نسخهٔ قبلی پشتیبان می‌گیرد، autostart را فقط با `~/.config/autostart/rooz.desktop` فعال می‌کند و ورودی قدیمی `ir.aasoft.rooz.desktop` را غیرفعال می‌کند تا دو نسخه هم‌زمان اجرا نشوند. نیازی به نصب با sudo نیست و پایگاه دادهٔ `~/.local/share/rooz/rooz.db` حذف نمی‌شود.

برای بررسی اینکه واقعاً نسخهٔ جدید اجرا می‌شود:

```bash
~/.local/bin/rooz --version
~/.local/bin/rooz --audio-check
pactl get-default-source
```

نسخهٔ 0.4.5 همچنین در سربرگ Rooz Intelligence شماره نسخه را نشان می‌دهد. از این نسخه به بعد ضبط بومی Linux (`parec --device=@DEFAULT_SOURCE@`) اولویت دارد؛ مرورگر دیگر اولین مسیر ضبط نیست. اگر `--audio-check` صدا را پیدا نکرد، بسته `libpulse` و سرویس PipeWire/PulseAudio را بررسی کنید.

```bash
sudo pacman -S --needed libpulse
pactl list short sources
pactl get-default-source
```

اگر منبع پیش‌فرض صحیح نبود، از Settings → Sound در KDE آن را انتخاب کنید یا طبق نام واقعی موجود در خروجی `pactl list short sources` از دستور `pactl set-default-source NAME` استفاده کنید.

**نکته:** کار نکردن Groq transcription با خطای شبکه یا API key به معنی کار نکردن میکروفن نیست. برنامه از این نسخه خطای ضبط را از خطای ارسال درخواست تبدیل گفتار به متن جدا می‌کند.

# روز ۰٫۳٫۲ — برنامه‌ریز رومیزی برای آرچ و KDE

بازنویسی نسخه‌ی قبلی با **Tauri 2 + Rust + SQLite + TypeScript**. رابط کاربری مینیمال اما چندلایه با شیشه‌ی نیمه‌شفاف، درخشش ظریف، حرکت سه‌بعدی واکنشی، انیمیشن‌های سبک و حالت ویجت/پنجره‌ی بزرگ.

> **وضعیت ساخت:** رابط TypeScript کامپایل شده و آزمون‌های تعاملی مرورگر موفق‌اند. این محیط ابزار Rust/Cargo ندارد، بنابراین **فایل اجرایی نیتیو هنوز کامپایل و تست نشده**. فایل ZIP شامل کد منبع و اسکریپت ساخت روی آرچ است.


## ساخت AppImage با GitHub Actions

این پروژه در CI **فقط AppImage** می‌سازد. در GitHub بخش **Actions → Rooz AppImage (x86_64)** را باز کن و گردش‌کار را اجرا کن. پس از موفقیت، فایل `*.AppImage` را از وب‌سایت serv00 در مسیر `/downloads/rooz/` دریافت کن. فایل SHA-256 و `latest.json` نیز در همین مسیر ایجاد می‌شوند؛ دیگر Artifacts یا GitHub Releases ساخته نمی‌شوند.

```fish
# پس از دانلود AppImage از serv00:
chmod +x ./Rooz*.AppImage
./Rooz*.AppImage
```

اگر می‌خواهی از همان مسیر قبلی `~/.local/bin/rooz` استفاده کنی، ابتدا برنامه را از Tray کاملاً Quit کن و AppImage جدید را با همان نام جایگزین کن. در صورت وجود فایل `~/.config/autostart/rooz.desktop`، برای اجرای خودکار نیازی به ساخت autostart دوم نیست. همچنین می‌توانی با اجرای `./scripts/install-appimage.sh ./Rooz*.AppImage` از سورس، لانچر و Autostart جدید نصب کنی؛ اما فقط یکی از این دو روش را انتخاب کن.

**دیتابیس:** فایل `~/.local/share/rooz/rooz.db` در این اصلاح تغییر نمی‌کند. **امنیت:** برای ذخیره کلیدهای API همچنان مجوز دسترسی `0600` استفاده می‌شود. آزمون‌های Python و TypeScript موفق‌اند، اما موفقیت ساخت Rust/Tauri باید با اجرا شدن GitHub Actions تأیید شود.

## بخش‌ها

- **روتین‌ها:** برنامه‌های تکرارشونده و کارهای بدون تاریخ، سابقهٔ انجام مستقل، وقفه/فعال‌سازی و یادآور.
- **تقویم:** نمای ماهانه، انتخاب روز و افزودن کار همان روز (مبنای فعلی میلادی است؛ نمایش بعضی تاریخ‌ها فارسی است).
- **یادداشت‌ها:** ویرایشگر غنی با نوار ابزار هنگام انتخاب متن، Markdown، ذخیره‌ی خودکار، لینک و دسته‌بندی.
- **تمرکز:** تایمر ۱۵/۲۵/۴۵/۶۰ دقیقه.
- **میانبرها:** `Ctrl+K` جست‌وجو؛ `Ctrl+1` تا `Ctrl+6` جابه‌جایی بین بخش‌ها؛ `/` رفتن به افزودن سریع.
- **اعلان صوتی:** از طریق `spd-say` (کیفیت فارسی وابسته به موتور گفتار نصب‌شده).

## دیتابیس نسخه‌ی قبل

همان فایل `~/.local/share/rooz/rooz.db` استفاده می‌شود؛ یادداشت‌های Markdown نسخه‌ی قبل حفظ می‌شوند و یک ستون جدید بدون حذف داده به جدول یادداشت اضافه خواهد شد. **برنامه‌ی GTK قدیمی را قبل از اجرای نسخه‌ی جدید ببندید.**

## X11 و Wayland

در **X11** کد Rust جای پنجره را در پایین سمت راست تعیین می‌کند. در **Wayland** جای‌دهی قطعی آزاد نیست و باید در KDE با **Window Rules** محل پنجره را مشخص کنید (KDE System Settings → Window Management → Window Rules). حالت کوچک ۴۳۸×۷۰۴ پیکسل است.

## حریم خصوصی و سرعت

بدون Electron، بدون Node.js در زمان اجرا، بدون فونت یا کتابخانه‌ی انیمیشن خارجی؛ تمام تسک‌ها و یادداشت‌ها در SQLite محلی‌اند. نمونه‌ی نمایشی در مرورگر از localStorage جداگانه استفاده می‌کند و به پایگاه داده‌ی اصلی منتقل نمی‌شود.

نسخه‌ی فعلی فاقد همگام‌سازی ابری، تقویم کاملاً جلالی، ویرایشگر کاملاً هم‌سطح Word و پیش‌نمایش کامل OpenGraph است؛ این قابلیت‌ها را نباید با امکانات پیاده‌سازی‌شده اشتباه گرفت.

## نسخهٔ ۰.۳ — بخش مستقل «روتین‌ها»

از نوار پایین، **روتین‌ها** را انتخاب کنید (میان‌بر `Ctrl+3`). این بخش از «کارهای امروز» جداست و برای کارهای دوره‌ای، برنامه‌های تکراری و کارهای بدون موعد ساخته شده است.

- **هر زمان:** مانند خرید، مراجعه به خدمات یا کارهای متفرقه؛ بدون تاریخ سررسید ثابت.
- **روزانه:** هر روز در فهرست روتین‌ها آمادهٔ ثبت انجام است.
- **روزهای انتخابی هفته:** مثلاً دوشنبه و پنجشنبه؛ امکان انتخاب چند روز.
- **هر چند روز:** مثلاً هر ۳ روز، بر اساس تاریخ شروع اولیه.
- **ماهانه:** روز مشخصی از ماه؛ اگر مثلاً روز ۳۱ برای یک ماه وجود نداشته باشد، آخرین روز همان ماه محاسبه می‌شود.

برای ساخت روتین از «جدید» استفاده کنید. عنوان، دسته‌بندی، توضیح، نوع تکرار، تاریخ شروع و در صورت نیاز ساعت و زمان یادآوری را تعیین کنید. با «ثبت انجام»، یک سابقهٔ جداگانه به تاریخ همان نوبت ذخیره می‌شود و قالب روتین حذف نمی‌شود. «سوابق» تاریخچهٔ ثبت‌ها را نشان می‌دهد و امکان بازگرداندن ثبت وجود دارد. از قسمت ویرایش می‌توان روتین را موقتاً غیرفعال کرد؛ سابقه همچنان باقی می‌ماند.

**پشتیبانی از داده‌های قبلی:** اطلاعات نسخهٔ ۰.۲.۱ در فایل `~/.local/share/rooz/rooz.db` باقی می‌مانند. سه جدول جدید به پایگاه داده افزوده می‌شوند و جدول‌های کارها، یادداشت‌ها و تنظیمات دست‌نخورده می‌مانند. پیش از ارتقا، اگر داده‌های مهمی دارید از این فایل نسخهٔ پشتیبان تهیه کنید.

**نکته:** تاریخ داخلی برنامه میلادی است؛ حالت فارسی راست‌به‌چپ و نمایش تاریخ به زبان فارسی را ارائه می‌دهد، اما انتخاب‌گر تاریخ شمسیِ بومی هنوز اضافه نشده است. یادآوری خودکار صرفاً برای روتین‌های برنامه‌دارِ دارای ساعت کار می‌کند و در حالت «هر زمان» ارسال نمی‌شود.

برای اجرای بررسی‌ها:

```bash
npm run typecheck && npm run build:web
python3 tests/test_routines_db.py
python3 tests/test_packaging.py
# روی سیستم دارای Rust:
cargo test --manifest-path src-tauri/Cargo.toml
```

### اصلاح نسخه ۰.۴.۲

خطای قبلی بعد از ساخته‌شدن AppImage و هنگام بررسی فایل رخ می‌داد. فایل `.desktop` واقعی در `usr/share/applications` قرار می‌گیرد و ورودی ریشه معمولاً پیوند نمادین است. اسکریپت بررسی جدید این ساختار را درست تشخیص می‌دهد و محتویات استخراج‌شده را آزمایش می‌کند. خروجی همچنان فقط AppImage است.


## نسخهٔ ۰٫۴٫۳ — اتصال به گوشهٔ پایین راست و اصلاح میکروفن

حالت‌های پنجره فقط دو مورد هستند: **پنل کوچک** و **تمام‌صفحه (F11)**.
حالت بزرگ‌شده و وسط صفحه حذف شده است. در نشست X11 پنجره مستقیم به گوشه منتقل می‌شود.
در KDE Plasma 6 با Wayland، برنامه یک اسکریپت KWin مخصوص «روز» نصب می‌کند تا پنجره
به پایینِ سمت راست فضای قابل‌استفاده متصل بماند. برای فعال‌سازی دستی:

```fish
~/.local/bin/rooz --install-kde-anchor
```

برای نسخهٔ فعلی AppImage نیز می‌توانید پیش از کامپایل نسخهٔ جدید،
`bash scripts/install-kde-anchor.sh` را از پوشهٔ سورس اجرا کنید.

در صورت نیاز یک بار از نشست KDE خارج و دوباره وارد شوید.
از قسمت System Settings → Window Management → KWin Scripts نیز فعال بودن
«Rooz · Bottom-right anchor» را بررسی کنید.

خطای `OverconstrainedError: Invalid constraint` مربوط به درخواست ضبط صدای
WebKitGTK است. ابتدا درخواست سادهٔ میکروفن امتحان می‌شود و در صورت خطا
برنامه از ابزار بومی `parec` استفاده می‌کند. برای نصب ابزارهای لازم:

```fish
sudo pacman -S --needed libpulse
wpctl status
```

این مسیر بدون نگه‌داشتن دکمه و با تشخیص تقریبی پایان گفتار کار می‌کند؛
اما اجرای واقعی با میکروفن و محیط PipeWire باید روی سیستم شما تست شود.
پایگاه داده و API‌های هوش مصنوعی تغییر نکرده‌اند. بسته‌بندی فقط AppImage است.

### نسخهٔ ۰.۴.۴ — رفع خطای Groq و جای‌گیری پنجره در KDE

خطای `curl: symbol lookup error ... nghttp2...` حاصل ناسازگاری کتابخانه‌های داخل AppImage با برنامهٔ `curl` سیستم بود. اکنون ارتباط با Groq/OpenRouter/NVIDIA مستقیماً با کلاینت HTTPS نوشته‌شده به Rust انجام می‌شود و برنامهٔ `curl` خارجی اجرا نمی‌شود. اجرای ابزارهای صدا مانند `parec` نیز از مسیر کتابخانه‌های بستهٔ AppImage جدا شده است.

حالت‌های پنجره فقط دو موردند: پنل کوچک در پایین راست (۴۳۸×۷۰۴) و تمام‌صفحه (F11). روی Wayland، جای‌گذاری قطعی به KWin نیاز دارد. نسخهٔ جدید اسکریپت مخصوص Rooz را با `kpackagetool6` ثبت و در صورت نیاز به‌روزرسانی می‌کند.

پس از ساخت و نصب AppImage جدید، نسخهٔ قبلی Rooz را کامل ببندید و برای ترمیم اسکریپت KDE یک بار اجرا کنید:

```bash
~/.local/bin/rooz --install-kde-anchor
```

اگر دستور `kpackagetool6` یا ضبط صدای `parec` موجود نیست:

```bash
sudo pacman -S --needed kpackage libpulse
```

در System Settings → Window Management → KWin Scripts مطمئن شوید **Rooz · Bottom-right anchor** فعال است. در صورت نیاز یک بار از نشست KDE خارج شوید و دوباره وارد شوید. جای‌گیری پنجره و ضبط صدا در محیط اصلی شما هنوز باید آزمایش شوند؛ تست‌های محیط توسعه جایگزین اجرای بومی روی Arch نیستند.
